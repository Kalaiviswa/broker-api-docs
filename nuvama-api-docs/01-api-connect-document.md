The Library API Connect is a set of REST-like APIs that expose many capabilities required to build a
complete investment and trading platform. Execute orders in real time, manage user portfolio, stream live market
data (WebSockets), and more, with the simple HTTP API collection This module provides an easy to use abstraction
over the HTTP APIs. The HTTP calls have been converted to methods and their JSON responses are returned.
