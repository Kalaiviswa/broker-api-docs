# OrderBook And TradeBook

## OrderBook (GET)

The Order Book contains the status of all orders placed by a user. The possible states of an order are referred to as the Order Status.

### URL

```http
GET https://developers.symphonyfintech.in/1interactive/orders?clientID=SYMP1
```

### Request Body Parameters

| Parameter Name | Type | Mandatory | Description |
| --- | --- | --- | --- |
| **clientID** | ClientID (String, 15) | **N** | Client ID Mandatory in case of Dealer |

### Response Body Parameters

| Parameter Name | Type | Description |
| --- | --- | --- |
| **LoginID** | UserID (String, 15) | User login ID |
| **ClientID** | ClientID (String, 15) | User specific identification |
| **AppOrderID** | AppOrderID (Integer, 10) | Unique order ID |
| **OrderReferenceID** | OrderReferenceID (String, 20) | It is unique OrderReferenceID to identify more than 1 leg orders. |
| **GeneratedBy** | GeneratedBy (String, 15) | It represents [Source](02-enums.md#7-ordersource) from which operation has been performed. |
| **ExchangeOrderID** | ExchangeOrderID (String, 20) | It is unique OrderID generated by exchange |
| **OrderCategoryType** | OrderCategoryType (String, 10) | It represents order market type, i.e. MarketType |
| **ExchangeSegment** | ExchangeSegment (String, 15) | [ExchangeSegment](02-enums.md#1-exchangesegments) |
| **ExchangeInstrumentID** | ExchangeInstrumentID (Integer, 10) | Exchange Scrip code or Symbol Token is unique identifier |
| **OrderSide** | OrderSide (String, 4) | [OrderSide](02-enums.md#4-orderside) |
| **OrderType** | OrderType (String, 10) | [OrderType](02-enums.md#3-ordertype) |
| **ProductType** | ProductType (String, 4) | [ProductType](02-enums.md#2-producttype) |
| **TimeInForce** | TimeInForce (String, 5) | [TimeInForce](02-enums.md#5-timeinforce) |
| **OrderPrice** | Price (Double, (15,4)) | The price to execute the order at |
| **OrderQuantity** | Quantity (Integer, 10) | Quantity to transact |
| **OrderStopPrice** | Price (Double, (15,4)) | The price at which an order should be triggered (SL, SL-M) |
| **OrderStatus** | OrderStatus (String, 20) | It is the status of order i.e. [OrderStatus](02-enums.md#6-order-status) |
| **OrderAverageTradedPrice** | OrderAverageTradedPrice | Average traded price, also referred as a Volume-Weighted Average Price |
| **LeavesQuantity** | Quantity (Integer, 10) | The remaining shares still left to buy/sell of a single instrument on an order. |
| **CumulativeQuantity** | Quantity (Integer, 10) | The total number of shares bought/sold on a single order for a single instrument |
| **OrderDisclosedQuantity** | Quantity (Integer, 10) | Quantity to disclose (for equity) |
| **OrderGeneratedDateTime** | Timestamps (String, 20) | Timestamp at which the order was registered by the API |
| **ExchangeTransactTime** | Timestamps (String, 20) | Timestamp at which the order was registered by the exchange |
| **LastUpdateDateTime** | Timestamps (String, 20) | Timestamp at which an order's state changed |
| **OrderExpiryDate** | OrderExpiryDate (String, 20) | It is order expiry date of order when validity set to GTD (Good Till Date) |
| **CancelRejectReason** | RejectReason (String, 500) | It is reason if order rejected or canceled |
| **OrderUniqueIdentifier** | OrderUniqueIdentifier (String, 20) | Echo back to identify order (20 char length) |
| **OrderLegStatus** | OrderLegStatus (String, 20) | It represents type of order i.e. [OrderLegStatus](02-enums.md#11-orderlegstatus) |
| **BoLegDetails** | BoLegDetails (String, 20) | Bracket Order Leg details i.e. [BoLegDetails](02-enums.md#12-bo_leg_details) |
| **IsSpread** | IsSpread (Boolean, 5) | Indicates Spread order or normal order |
| **BoEntryOrderID** | AppOrderID (Integer, 10) | Unique order ID |
| **MessageCode** | MessageCode (String, 10) | API MessageCode |
| **MessageVersion** | MessageVersion (String, 10) | API Message Version |
| **TokenID** | TokenID (String, 10) | API TokenID |
| **ApplicationType** | ApplicationType (String, 15) | API ApplicationType |
| **SequenceNumber** | SequenceNumber (String, 15) | API SequenceNumber |

## TradeBook (GET)

The trade book returns a list of all trades executed on a particular day that were placed by the user. It displays all filled and partially filled orders.

### URL

```http
GET http://160.30.125.86:10955/interactive/orders/trades
```

## Order History (GET)

Order History provides the complete trail of a particular order, showing all its state changes.  
For example: **New → New, New → Partially Filled, Partially Filled → Partially Filled, and Partially Filled → Filled, etc.**

### URL

```http
GET https://developers.symphonyfintech.in/orders?appOrderID=1210999833
```

### Request Body Parameters

| Parameter Name | Type | Mandatory | Description |
| --- | --- | --- | --- |
| **appOrderID** | AppKey (String, 15) | **N** | Unique order ID |

### Response Body Parameters

| Parameter Name | Type | Description |
| --- | --- | --- |
| **LoginID** | LoginID (String, 15) | User login ID |
| **ClientID** | ClientID (String, 15) | User specific identification |
| **AppOrderID** | AppOrderID (String, 15) | Unique order ID |

| **GeneratedBy** | GeneratedBy (String, 15) | Represents source from which operation was performed |
| **ExchangeOrderID** | ExchangeOrderID (String, 20) | Unique Order ID generated by exchange |
| **OrderCategoryType** | OrderCategoryType (String, 15) | Represents order market type |
| **ExchangeSegment** | ExchangeSegment (String, 15) | Exchange Segment |
| **ExchangeInstrumentID** | ExchangeInstrumentID (Integer, 10) | Exchange scrip code or symbol token |
| **OrderSide** | OrderSide (String, 4) | Order side (Buy / Sell) |
| **OrderType** | OrderType (String, 10) | Type of order (Limit / Market / SL / SL-M) |
| **ProductType** | ProductType (String, 4) | Product type of order |
| **OrderStatus** | OrderStatus (String, 20) | Status of the order |
| **TokenID** | TokenID (String, 10) | API Token ID |
| **ApplicationType** | ApplicationType (String, 15) | API application type |
